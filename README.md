# My First C Project

Welcome to my first programming repository! This project contains basic C code programs created while learning how to use Visual Studio Code and GitHub.

## Files in this Repository

- **`main.c`**: My main C program containing a simple "Hello World" example.
- **`user_input.c`**: A program that takes user age input and calculates next year's age.
- **`README.md`**: Project documentation and notes.

## How to Run

1. Open any `.c` file in VS Code or any C editor.
2. Compile and run the file using a C compiler.
